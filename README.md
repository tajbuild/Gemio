# 2D Platformer - AI Game Dev Project

## About The Project
This repository contains the source code for a 2D platformer built using Unity 6 and C#. The game is actively being developed iteratively with the assistance of Gemini AI, exploring how artificial intelligence can help architect game systems, write scripts, and polish mechanics.

I am documenting the entire, raw development process on YouTube. I share unedited progress videos so others can follow along with the exact steps, problem-solving, and logic used to build the game from the ground up.

## Current Features
* **Mobile-Ready Controls:** Configured with a universal UI canvas prefab for consistent scaling across levels.
* **Dynamic UI Management:** Real-time level tracking and score updates handled by a centralized `UIManager`.
* **Game Feel & Polish:** Custom particle bursts and audio cues for collecting items (oranges/coins).
* **Multi-Level Architecture:** A scalable scene structure utilizing Unity's Build Settings and SceneManager.

## Getting Started
To run this project locally:
1. Clone this repository.
2. Open the project folder via the Unity Hub (ensure you are using Unity 6).
3. Open the `MainMenu` or `Level_01` scene located in the `Scenes` folder.
4. Hit Play!
